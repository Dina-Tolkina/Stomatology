# Система управления стоматологической клиникой
## Описание
Этот проект представляет собой веб-приложение, разработанное на Django, для управления деятельностью стоматологической клиники. Оно предоставляет удобную платформу для пациентов, врачей и администраторов для управления записями на консультации, услугами, пользователями и статьями, связанными со стоматологической помощью. Система включает функции аутентификации пользователей, планирования консультаций, категоризации услуг и административную панель для управления данными.

## Функционал
1. Аутентификация пользователей:
  - Регистрация, вход и выход из системы для пациентов.
  - Ролевая модель доступа для пациентов, врачей и администраторов.
2. Управление консультациями:
  - Пациенты могут записываться на консультации к врачам в доступные временные слоты.
  - Динамическая загрузка доступных услуг, дат и времени для выбранных врачей.
  - Админ-панель для управления статусами консультаций и журналами коммуникаций.
3. Управление услугами:
  - Услуги разделены по категориям и связаны с конкретными врачами.
  - Подробное описание услуг, цены и изображения.
4. Профили врачей:
  - Отображение информации о врачах, включая специализации, образование и стаж работы.
5. Система статей:
  - Публикация и управление статьями с категориями, такими как акции, новости клиники.
  - Фильтрация и поиск статей с указанием дат публикации и окончания.
6. Административная панель:
  - Настраиваемая админ-панель с функцией архивации/восстановления вместо удаления.
  - Массовая установка расписания для врачей.
  - Фильтры для консультаций по датам, врачам и дням недели.
7. Адаптивный дизайн: Шаблоны для главной страницы, профилей, услуг, врачей, статей и контактной информации.

## Используемые технологии
- **Backend**: Django, Python
- **База данных**: PostgreSQL (с использованием Django ORM)
- **Frontend**: HTML, CSS, JavaScript (с AJAX для динамических форм)
- **Редактор текста**: CKEditor 5 для контента статей
- **Зависимости**: `django-ckeditor-5`, `django-smart-selects`

## Как установить и запустить
### Установка и запуск (локально на ПК)
1. Клонирование репозитория
  ```sh
  git clone https://github.com/Dina-Tolkina/Stomatology
  ```
2. Создать venv
  ```sh
  python -m venv venv
  ```
3. Активация виртуальной среды:
- Для Windows:
  ```sh
  venv\Scripts\activate
  ```
- Для Unix или MacOS:
  ```sh
  source venv/bin/activate
  ```
4. Установка зависимостей:
  ```sh
  pip install -r requirements.txt
  ```
5. Настройка базы данных:
    - Создать файл .env
    - Указать настройки базы данных в файле .env
    ```sh
      DB_NAME=database_name
      DB_USER=username
      DB_PASSWORD=password
      DB_HOST=db
      DB_PORT=5432
    ```
    - Применить миграции:
   ```sh
   python manage.py migrate
   ```
6. Запуск команды для создания суперпользователя
     ```sh
    python manage.py createsuperuser
    ```
7. Запуск сервера:
   ```sh
    python manage.py runserver
    ```
   - Открыть веб-браузер и перейти по адресу [http://127.0.0.1:8000/](http://127.0.0.1:8000/), чтобы открыть главную страницу сайта:
   - Для входа в административную панель использовать [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/).  
    Ввести учетные данные суперпользователя, созданного ранее через команду createsuperuser.
